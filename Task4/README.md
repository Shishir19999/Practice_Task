# Task 4 - Protected Routes

React Router (Vite) example with a login page and a protected `/dashboard` route. Demo credentials: username `user`, password `password`. Auth state is a flag in `localStorage` (demo only, not real security).

```bash
npm install
npm run dev
npm run build
```

## Tooling (updated 2026-10-06)


React 19.3, Vite 8, react-router-dom 7.18, ESLint 9. Requires Node ^20.19 or >=22.12.
