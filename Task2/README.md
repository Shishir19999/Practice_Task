# Task 2 - User List

A React (Vite) component that fetches users from JSONPlaceholder (`/users`) and renders their names in an ordered list.

```bash
npm install
npm run dev
npm run build
```

## Tooling (updated 2026-10-06)

React 19.3, Vite 8, @vitejs/plugin-react 6, ESLint 9 (flat config). Requires Node ^20.19 or >=22.12.
